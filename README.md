# ANN on Fashion MNIST using PyTorch

## Project Overview
This is a simple deep learning project where I trained an _Artificial Neural Network (ANN)_ on the **Fashion MNIST dataset** using **PyTorch**.  
The goal of this notebook is to understand the basic workflow of training a neural network with GPU support.

## What I Did in This Notebook
* Loaded the Fashion MNIST dataset
* Performed basic data preprocessing
* Split the dataset into train and test
* Normalized the pixel values
* Created a custom PyTorch Dataset
* Built a simple ANN model
* Trained the model using GPU (if available)
* Evaluated the model performance

## Technologies Used
- Python
- PyTorch
- Pandas
- Scikit-learn
- Google Colab

## Dataset
- Fashion MNIST dataset
- Contains grayscale images of clothing items
- Each image size is **28 x 28 pixels**
